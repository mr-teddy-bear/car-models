# Автознайка

Небольшая детская игра для запоминания марок автомобилей. Ребёнок смотрит на фотографию, слушает название марки и отмечает, знает её или пока учит.

## Возможности

- 32 популярные марки и 192 фотографии автомобилей;
- отдельный крупный логотип на каждой карточке;
- 30 случайно выбранных вопросов в основном заезде;
- русская озвучка названий средствами браузера;
- случайный порядок марок и фотографий в каждом заезде;
- предзагрузка следующей фотографии и индикатор загрузки;
- отдельный повтор незнакомых марок;
- адаптивный интерфейс для телефона, планшета и компьютера;
- изображения с Wikimedia Commons со ссылкой на страницу каждого файла.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Публикация на Vercel

1. Импортируйте этот GitHub-репозиторий в Vercel.
2. Vercel автоматически определит Vite.
3. Build command: `npm run build`, output directory: `dist`.

Дополнительные переменные окружения не нужны.

## Медиа и лицензии

Фотографии загружаются с [Wikimedia Commons](https://commons.wikimedia.org/). Ссылка на исходную страницу и сведения о лицензии доступны прямо на каждой карточке. Авторские права и условия использования зависят от конкретного файла.
